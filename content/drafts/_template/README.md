# Project folder template

Copy this folder to `content/drafts/<project-slug>/` at the start of every video.

```
content/drafts/my-project/
├── brief.md        # what it is, audience, length, engine choice, deadline
├── script.md       # the script / narration, one line per spoken beat
├── beats.md        # beat table (cinematic-film) or storyboard panels (animate)
├── credits.md      # EVERY asset: source URL + licence + author
└── delivery.md     # export checklist + final filenames
```

Engine choice goes in `brief.md` — see the decision table in `AGENTS.md` § 0:

| Need | Engine |
| --- | --- |
| Branded motion graphics / lower thirds over your footage | Remotion |
| Long-form narrated documentary / Vox explainer | `cinematic-film` |
| Short-form illustrated explainer / story | `animate` |
| 3D / product / scientific visualisation | `3dviz-pro-max` |
| Narrative anime | `make-an-anime` |
| Cutting & conforming finished footage | FFmpeg |
