## Type

Display: **DejaVu Sans Bold**, tight tracking on large sizes, wide tracking on small uppercase kickers.
Body: **DejaVu Serif** at 10.2 / 15.9, justified.

## Recurring design language

* A four-point orange diamond as the only ornament.
* Chapter openings: small letter-spaced kicker → oversized title → 54 pt orange rule.
* Pull quotes sit in a cream panel with a 4 pt orange spine.
* Scripture sits centred between two gold rules, reference tracked in orange.
* Images are always drawn inside rounded rectangles or full-bleed with a navy veil.
* Page foot: `UNUSED IS LOST` … page number, in small tracked caps.

## Source design reference

The interior system is adapted from `library/design-references/school-prospectus-22pp.pdf` — a 22-page,
image-led template with numbered sections, bold sans display type and energetic colour blocking.
It was chosen over the other three uploads because its structure (welcome → values → programme → life →
joining → dates) maps directly onto a youth-movement book. See `library/README.md`.
