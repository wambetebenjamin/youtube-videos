## Design system

The interior follows the **SCHOOL BOOK** reference (`library/design-references/school-prospectus-22pp.pdf`
— a Canva-developed 22-page prospectus) rather than an invented house style. Everything below is taken
from that file.

| Token | Hex | Where |
|---|---|---|
| Template blue | `#2a49f2` | full-bleed fields, headings, rules, page numbers |
| Orange | `#fa6704` | pills, numbered circles, date chips |
| Green | `#67cf4e` | organic accent squiggles |
| Light blue | `#5d81ec` | secondary shapes |
| Grey | `#ececec` | decorative blobs |
| White | `#ffffff` | type on blue, page fields |

**Type scale:** display 62 / 45 pt (bold grotesque, tight tracking), sub-head 21 pt, card head 14 pt,
body 10 pt / 13.6 pt leading, list rows 12 pt, page number 10 pt bold bottom-left. DejaVu Sans is the
free stand-in for the template's Anantason.

**Recurring furniture:** blue field with a wavy lower edge · photos in rounded or organic windows with
torn-paper wedge cuts · orange pill labels · star icon bullets · hairline rules between list rows.
